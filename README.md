# CircuitX

Open-source AI code agent for Visual Studio Code.

## Features

CircuitX provides AI-powered coding assistance directly in VS Code.

## Requirements

- VS Code version 1.107.0 or higher

## Installation

Install from the VS Code Marketplace or download the `.vsix` file.

## Usage

Use the Command Palette (Cmd+Shift+P) to access CircuitX commands.
